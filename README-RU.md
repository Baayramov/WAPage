# WAPage

WhatsApp предоставляет функцию экспорта переписки, но не предлагает официального инструмента для последующего чтения. Это приложение было создано, чтобы восполнить этот пробел. <br> WAPage анализирует экспортированные файлы чатов WhatsApp и отображает их в удобном визуальном интерфейсе. <br>
Что отличает эту программу от других программ для чтения, так это то, что она работает на C++ в формате .exe, не требует браузера и является открытым исходным кодом.

### Особенности

- Поддерживает экспорт как для Android, так и для iOS.
- Дизайн интерфейса, максимально точно отражающий известный визуальный стиль приложения.
- Светлая и темная темы оформления
- Интерфейс доступен на 18 языках — язык интерфейса не влияет на содержимое чатов
- Поддержка как индивидуальных (один на один), так и групповых бесед
- Поддержка как простых, так и анимированных стикеров, отправленных в чат
- Обнаружение и отображение всех отправленных медиафайлов, голосовых сообщений, общих контактов и текстовых сообщений
- Переход непосредственно к первому сообщению в чате
- Возможность переименовывать беседы и устанавливать пользовательские фотографии профиля
- Ссылки в чатах кликабельны и открываются в браузере по умолчанию
- Сообщения с указанием местоположения открывают координаты на карте через браузер
- Полностью автономный режим — подключение к интернету не устанавливается, все данные остаются на компьютере пользователя
- Низкое потребление ресурсов, разработан для плавной работы даже на слабом оборудовании
- Написано более <b>13.000+</b> строк кода <br><br>

### Поддерживаемые типы экспорта

| Платформа | С медиафайлами   | Только чат (без медиафайлов) |
|-----------|------------------|------------------------------|
|  Android  |  Поддерживается  |       Поддерживается         |
|  iOS      |  Поддерживается  |       Поддерживается         |

**Важно:** В настоящее время парсер чата поддерживает только экспорт данных, выполненный с устройства, в котором язык системы установлен на английский. Это необходимо, поскольку данные о часовых поясах и сообщения, генерируемые системой (например, события присоединения/выхода из группы, изменения имени и т. д.), распознаются только в формате экспорта на английском языке. Содержимое чатов — сообщения, имена и медиафайлы — может быть на любом языке без ограничений.

### Инструкция по компиляции
Чтобы скомпилировать проект из исходного кода, внимательно следуйте этим шагам, чтобы убедиться, что все необходимые зависимости правильно установлены с помощью Qt Maintenance Tool.

**1. Установка необходимых компонентов Qt**

- Откройте Qt Maintenance Tool. Перейдите в раздел Customize и убедитесь, что в фильтре Show в правом верхнем углу активирована опция Archive.
- В разделе Qt 6.7.3 выберите и установите следующие модули:
  - MSVC 2022 64-bit
  - Qt 5 Compatibility Module
  - Qt Shader Tools
- В разделе Qt 6.7.3 -> Additional Libraries выберите и установите:
  - Qt Image Formats
  - Qt Multimedia
- В разделе Qt Development -> Build Tools выберите и установите:
  - CMake 3.30.5
  - Ninja 1.12.1
- В разделе Qt Creator выберите и установите:
  - Qt Creator 19.0.0

**2. Компиляция проекта**

- Запустите Qt Creator. Нажмите Open Project... и выберите файл `CMakeLists.txt`, находящийся в папке с исходным кодом.
- На экране Kit Selection обязательно выберите Desktop Qt 6.7.3 MSVC2022 64-bit.
- Рекомендуется установить конфигурацию сборки Release. Для оптимальной производительности приложению необходимы специальные DLL-файлы в папке release. (Вы также можете выбрать Debug для проверки ошибок, однако это приведёт к заметному снижению производительности программы).
- Нажмите Configure Project и дождитесь завершения процесса.
- После успешного завершения конфигурации кнопка Build (значок молотка в левом нижнем углу) станет активной. Нажмите её, чтобы начать компиляцию.
- После успешного завершения сборки внутри папки проекта будет создана новая папка `build`. Чтобы найти полностью скомпилированный исполняемый файл программы, перейдите в папку `Desktop_Qt_6_7_3_MSVC2022_64bit-Release` или `Desktop_Qt_6_7_3_MSVC2022_64bit-Debug` внутри неё.
